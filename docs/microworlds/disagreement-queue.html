Briefing · how to read this world

One model books every value. The others are professional skeptics.

TRIDENT-Val's registry holds a champion and two challengers. The champion's number is the book; the challengers score the same portfolio in shadow. When they disagree beyond a threshold, the asset routes to a human. This world walks five assets through that machinery.

lgbm_v1 · championBoosted trees, holdout MAPE 7.88%. Books current_avm_value for all 2,930 assets. Explains itself with TreeSHAP.
linear_v1 · challengerRidge regression, MAPE 8.02%. One global coefficient per feature — structurally blind to interactions, which is exactly what makes its dissent informative.
evolved_v1 · challengerThe OpenEvolve-searched blend (MAPE 7.82%) from ADR-0018 — bagged trees + boosting + a KNN voice that prices from comparables.
The queueGET /api/v1/models/disagreements: assets where challenger and champion diverge beyond a threshold, ranked by divergence. Depth is set by the threshold — that's this world's playable decision.
The humanAn underwriter resolves each queued asset via POST /properties/{pid}/triage-decision: book the champion, adopt a challenger, or set a manual value — rationale required, everything logged.
The other netsVariance-vs-sale triage (>15% flagged, 8–15% pending — ADR-0004) and revaluation-cycle flags. Additive to the disagreement net, not replaced by it.

Controls: scrub the tape (click any segment), or ←/→ and space. Change the threshold in the header at any time. Hover dots and cards for detail.

Honesty note: the mechanism is real — endpoints, field names, thresholds (10% default; 5/10/20/30% offered in ModelCompare), the audit-status bands, role gates, and log format all come from the code, and registry metrics from the model manifests. The five sample assets, the portfolio divergence distribution, queue depths, and the error-overlap figures are illustrative — run GET /api/v1/models/compare against your live registry for the real ones. The live queue endpoint compares the champion to one challenger at a time; this world uses the max across both challengers, the way the per-asset report does (reports.py, DISAGREEMENT_THRESHOLD).
